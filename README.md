# 云阅读

一个无需安装、在浏览器本地运行且可离线使用的 EPUB / TXT 阅读器。下载或克隆后直接打开 `txt.html` 即可使用。

![上传页](assets/screenshots/upload.png)

![阅读页](assets/screenshots/reader.png)

## 功能

- 导入 `.epub` 与单个 `.txt` 文件。
- TXT 自动识别 UTF-8、UTF-16LE、UTF-16BE 与 GB18030/GBK 编码。
- 自动识别常见中文章节标题；没有章节标记的长 TXT 会按内容长度切分为可阅读的部分。
- EPUB 读取书名、作者、章节顺序和正文图片。
- 左侧目录、章节跳转、键盘快捷键与移动端左右滑动翻章。
- 无缝长页阅读：接近当前内容底部时加载下一章，并回收远处的章节 DOM。
- 五种预设主题和自定义背景色；可调整字号、字体与行距。
- 本地保存阅读设置和阅读进度；阅读内容不会上传到服务器。

## 使用方法

1. 下载本项目，双击打开 `txt.html`。
2. 点击上传区，或将一个 EPUB / TXT 文件拖入上传区。
3. 打开目录选择章节，或直接滚动阅读。
4. 右侧浮动工具栏提供目录、夜间模式、阅读设置、返回书架和回到本章顶部。

### 快捷操作

| 操作 | 效果 |
| --- | --- |
| `←` / `→` | 上一章 / 下一章 |
| `Space`、`PageDown` | 向下翻页 |
| `PageUp` | 向上翻页 |
| `T` | 打开目录 |
| `N` | 切换夜间模式 |
| `B` | 返回上传页 |
| `M` | 显示或隐藏右侧工具栏 |
| `Tab` | 固定或取消固定右侧工具栏 |
| 移动端左右滑动 | 切换章节 |

## 隐私与数据

电子书正文在浏览器本地解析和渲染。阅读设置与进度使用浏览器 `localStorage` 保存；清除本站点数据会删除这些记录。EPUB 解析所需的 JSZip 3.10.1 已固定在 `vendor/` 中，页面不会为此请求 CDN 或检测网络状态。

## 已知范围

- 当前版本一次导入一本 EPUB 或一个 TXT。多文件章节导入、章节清单和全文索引尚未包含在此版本中。
- 文件由浏览器会话持有；刷新页面后，如要重新打开书籍，需再次选择源文件。
- 建议使用最新 Chrome、Edge、Firefox 或 Safari。
