# 云阅读

[English](README.en.md)

一个无需安装、在浏览器本地运行且可离线使用的 EPUB / TXT 阅读器。下载或克隆后直接打开 `txt.html` 即可使用。

当前版本：**v1.1.0** · [更新前版本 v1.0.0](https://github.com/z-luio/cloud-reader/releases/tag/v1.0.0) · [更新后版本 v1.1.0](https://github.com/z-luio/cloud-reader/releases/tag/v1.1.0)

## 功能

- 导入 `.epub`、单个 `.txt`、多个 `.txt` 文件或整个 TXT 文件夹。
- 多 TXT 文件按文件名自然排序，一个文件对应一个章节，支持连续阅读和目录跳转。
- TXT 自动识别 UTF-8、UTF-16LE、UTF-16BE 与 GB18030/GBK 编码。
- 自动识别常见中文章节标题；没有章节标记的长 TXT 会按内容长度切分为可阅读的部分。
- EPUB 读取书名、作者、章节顺序和正文图片。
- 左侧目录、章节跳转、键盘快捷键与移动端左右滑动翻章。
- 无缝长页阅读：接近当前内容底部时加载下一章，并回收远处的章节 DOM。
- 多 TXT 按需读取章节，最多两个预加载任务并发，并限制章节缓存和阅读 DOM 窗口。
- 批量导入显示进度，支持取消；切换书籍时会终止旧任务并清理缓存。
- 五种预设主题和自定义背景色；可调整字号、字体与行距。
- 本地保存阅读设置和阅读进度；阅读内容不会上传到服务器。

## 使用方法

1. 下载本项目，双击打开 `txt.html`。
2. 点击上传区，或将一个 EPUB / TXT 文件拖入上传区；也可以选择多个 TXT 或 TXT 文件夹。
3. 打开目录选择章节，或直接滚动阅读。
4. 右侧浮动工具栏提供目录、夜间模式、阅读设置、返回书架和回到本章顶部。

### 快捷操作

| 操作 | 效果 |
| --- | --- |
| `←` / `→` | 上一章 / 下一章 |
| `Space`、`PageDown` | 向下翻页 |
| `PageUp` | 向上翻页 |
| `T` | 打开目录 |
| `N` | 切换夜间模式 |
| `B` | 返回上传页 |
| `M` | 显示或隐藏右侧工具栏 |
| `Tab` | 固定或取消固定右侧工具栏 |
| 移动端左右滑动 | 切换章节 |

## 隐私与数据

电子书正文在浏览器本地解析和渲染，不会上传服务器。阅读设置与阅读进度使用浏览器 `localStorage` 保存；清除本站点数据会删除这些记录。多 TXT 只保存文件元数据和阅读位置，正文按章节读取并使用有限缓存。导入 TXT 时限制最多 2000 个文件、单文件 50 MB、总大小 512 MB；内容经过 HTML 转义后再渲染。导入 EPUB 时，阅读器会在浏览器报告在线时优先加载带 SHA-512 完整性校验的固定版本 JSZip CDN；网络离线、请求超时、加载失败或完整性校验失败时，自动改用 `vendor/` 中已内置的相同版本。TXT 阅读不会加载该库。

## 已知范围

- 当前版本一次导入一本 EPUB，或一组 TXT 文件。多 TXT 模式默认一个文件对应一个章节，不会对每个文件再次扫描内部章节。
- 文件由浏览器会话持有；刷新页面后，如要重新打开书籍，需再次选择源文件。
- 超大单个 TXT 的流式章节索引和全文索引尚未包含在此版本中。
- 建议使用最新 Chrome、Edge、Firefox 或 Safari。
